Home Server Project

Deskripsi Proyek

Proyek ini merupakan implementasi Home Server pribadi yang berfungsi sebagai pusat kendali berbagai layanan digital di lingkungan lokal. Server ini dirancang untuk meng-host aplikasi web pribadi, sistem manajemen data, penyimpanan awan, serta layanan pemantauan berbasis container.

Server dijalankan menggunakan Proxmox Virtual Environment dengan beberapa container Docker yang mengelola layanan seperti Nextcloud untuk penyimpanan file pribadi, Grafana dan Prometheus untuk monitoring resource, serta untuk automasi notifikasi.

Fitur Utama

  • Menjalankan beberapa container menggunakan Docker dan Proxmox
  • Penyimpanan awan pribadi menggunakan Nextcloud + MariaDB
  • Monitoring sistem dengan Grafana, cAdvisor, dan mysqld-exporter
  • Automasi tugas dan notifikasi Telegram menggunakan
  • Backup otomatis dan remote access dengan SSH key

Teknologi yang Digunakan

  • Proxmox VE
  • Docker & Docker Compose
  • Nextcloud + MariaDB
  • Grafana + Prometheus
  • Automations
  • Ubuntu Server

Hasil & Manfaat

Sistem ini berhasil mengintegrasikan berbagai layanan dalam satu server fisik, menghemat biaya cloud dan meningkatkan kontrol penuh terhadap data pribadi. Dengan automasi dan pemantauan real-time, performa sistem dapat dijaga stabil, serta peringatan dapat dikirim otomatis saat terjadi resource overload.
