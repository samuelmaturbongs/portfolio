Grafana & Prometheus Monitoring System

Sistem monitoring berbasis Grafana dan Prometheus untuk memantau performa server, container, dan aplikasi Laravel secara real-time dengan visualisasi interaktif.

Fitur Utama

  • Integrasi Prometheus untuk pengumpulan metrik real-time
  • Dashboard Grafana dengan panel visual interaktif
  • Monitoring Docker container menggunakan cAdvisor
  • Integrasi MySQL Exporter, PHP-FPM Exporter, dan Node Exporter
  • Notifikasi otomatis via Telegram jika terjadi overload
  • Pemantauan performa aplikasi Laravel dan database

Teknologi yang Digunakan

Grafana Prometheus Docker cAdvisor MySQL Exporter PHP-FPM Exporter Telegram Bot

Hasil: Sistem monitoring ini membantu mengidentifikasi bottleneck performa lebih cepat, memastikan ketersediaan server tetap stabil, dan mengurangi downtime hingga 40% melalui deteksi dini dan alert otomatis.
